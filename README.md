# Holo · Imaad

Identity card with a holographic foil surface — pointer tilt, lagged laminate, material playground.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Swap the photo at `public/holo/imaad.jpg` and the name/line in `src/components/holo/HoloCard.tsx`.
